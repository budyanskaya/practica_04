# Практика на Лекция_04
Алгоритм действий:
1. Нажмите кнопку Reset (Сброс - круговая стрелка) в левом верхнем углу сайта.
2. Выставите строго те параметры, которые указаны в строке вашего задания.
3. Нажмите кнопку Play (Запуск).
4. Наблюдайте за процессом. Остановите обучение (кнопка Pause), когда линия ошибки на графике справа (Test loss / Training loss) перестанет снижаться или опустится ниже 0.05.
5. Зафиксируйте результаты для отчета (см. требования в конце документа).
